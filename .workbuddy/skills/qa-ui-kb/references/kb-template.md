# UI 知识库模板（kb-template）

每个页面一份记录，包含三件套。可直接复制填写。

```markdown
# 页面知识库：<页面名>

## 1. 页面结构树
<页面名>
├── 顶部：导航菜单 button、设备号显示
├── 列表区：表格（行=记录）、操作列（编辑/删除 span）
└── 底部：分页、新增按钮

## 2. 关键元素表
| 元素 | 定位方式 | 用途 | 验证状态 |
|---|---|---|---|
| 导航菜单 | getByRole('button',{name:'导航菜单'}) | 打开侧边菜单 | ✅已验证 |
| 新增按钮 | getByTestId('btn-add') | 打开新增表单 | ✅已验证 |
| 列表行 | .grid-row | 遍历记录 | ✅已验证 |
| 操作-编辑 | getByRole('button',{name:'编辑'}) 限行内 | 打开编辑 | ✅已验证 |

## 3. 陷阱与注意事项
- 配置列表的父行也有 .status-badge，查询状态必须限定在子行内。
- 折叠的子行不在 DOM 中，需先展开再操作。
- 操作按钮是 <span> 不是 <button>，必须用 locator.click()。
- 弹窗确定按钮与页面另一确定重名，需用上下文限定。
```

## 填写纪律
- 选择器写「定位表达式」，不要只写 CSS 串；标注语义优先。
- 「验证状态」必须填：✅已验证 / ⚠️待验证 / ❌失效。未验证的不写进知识库主体。
- 陷阱笔记比选择器本身更值钱，务必记录「为什么这么定位」。
