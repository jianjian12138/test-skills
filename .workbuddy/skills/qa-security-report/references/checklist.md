# 安全风险报告检查清单与常见坑（qa-security-report）

## 1. 风险评级要素
- CVSS v3.1 基础分（AV/AC/PR/UI/S/C/I/A 向量）→ 0~10
- 严重级映射：9.0+ 严重 / 7.0–8.9 高 / 4.0–6.9 中 / 0.1–3.9 低 / 0 信息
- EPSS：被利用概率（优先级参考，非评级）
- 业务上下文可上调/下调（如内网 vs 公网）

## 2. 合规映射
| 框架 | 关注 |
| --- | --- |
| 等保 2.0 | 身份鉴别 / 访问控制 / 审计 / 加密 |
| GDPR | 个人数据最小化 / 同意 / 跨境 |
| PCI-DSS | 卡号不落地 / 加密 / 隔离 |

## 3. 整改清单必备
- [ ] 风险 ID + 严重级 + CVSS 向量
- [ ] 位置（文件/接口/行）
- [ ] 修复建议（具体）
- [ ] 责任人 / 期限
- [ ] 复测状态

## 4. 常见坑
- 只给"高危"不写 CVSS → 无法横向量化。
- 不区分可利用性（EPSS）→ 修复排期盲目。
- 漏合规映射 → 审计不通过。
