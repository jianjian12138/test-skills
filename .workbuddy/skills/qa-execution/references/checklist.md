# 执行编排检查清单与常见坑（qa-execution）

## 1. 进度矩阵要素
- [ ] 用例 × 类型（功能/接口/UI/性能/安全）覆盖
- [ ] 每用例状态：通过 / 失败 / 阻塞 / 未执行
- [ ] 失败归类：环境 / 数据 / 产品 bug

## 2. 失败自动分类规则
- 环境类：连接失败 / 502 / 服务不可用 → 先排查环境
- 数据类：参数缺失 / 前置数据不对 → 造数重跑
- 产品 bug：断言失败且环境数据正常 → 转 qa-bug-report

## 3. 重试策略
- 环境/网络抖动：有限重试（指数退避）
- 产品 bug：不重试，直接提单
- 幂等：可重试接口需保证幂等

## 4. 常见坑
- 失败不分类 → 大量"假失败"淹没真 bug。
- 无重试 → 偶发网络失败误判。
- 进度不透明 → 无法判断是否可发布。
