# 八大测试维度交叉矩阵（自检模板）

> 配套 `qa-risk-based` 的「八大测试维度交叉矩阵」增强。用例设计/评审时，用本表逐用例
> 标注其覆盖的维度，避免只在「交互」维度堆用例、漏掉安全/资损/埋点等隐蔽维度。

## 维度定义

| 维度 | 关注点 | 典型漏测信号 |
|---|---|---|
| 交互 | UI/UX 正常流程 | 异常态、空态、加载中 |
| 服务端 | 接口/逻辑/数据 | 幂等、并发、事务回滚 |
| 安全合规 | 越权/注入/合规 | 横向越权、敏感信息泄露 |
| 资损 | 金额/账务/对账 | 见下方 L1–L4 |
| 性能 | 响应/吞吐/资源 | 慢查询、内存泄漏、N+1 |
| 国际化 | 多语言/时区/币种 | 时区错算、RTL 布局、币种精度 |
| 兼容 | 端/版本/浏览器 | 旧版本、移动端、降级态 |
| 埋点 | 数据上报/可观测 | 漏报、错报、重复上报 |

## 资损代码血缘分级（L1–L4）

| 级别 | 影响面 | 测试密度 |
|---|---|---|
| L1 核心账务 | 直接改金额/余额/对账（支付、清结算） | 穷尽 + 回归 + 资金对账 |
| L2 交易链路 | 下单/退款/优惠券等强关联账务 | 重点 + 回归 |
| L3 边缘业务 | 积分/权益等弱关联 | 正常覆盖 |
| L4 非资金 | 纯展示/配置 | 冒烟即可 |
