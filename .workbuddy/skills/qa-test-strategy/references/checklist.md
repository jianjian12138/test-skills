# 测试策略检查清单与常见坑（qa-test-strategy）

## 1. 风险驱动策略
- 按模块风险（概率×影响）分配测试深度
- 高风险：多类型覆盖（功能+接口+性能+安全）
- 低风险：冒烟 + 抽样

## 2. 准入 / 准出标准库
| 标准 | 准入（可开测） | 准出（可发布） |
| --- | --- | --- |
| 需求 | 已评审冻结 | 无新增阻断 |
| 用例 | 评审通过 | 全部执行 |
| 缺陷 | 无 S1 遗留 | S1/S2 全清 |
| 性能 | 基线已建 | 达 SLA |
| 安全 | 扫描计划 | 无高危未修 |

## 3. 常见坑
- 平均用力 → 高风险模块覆盖不足。
- 无准出标准 → 带病上线。
- 策略不写风险 → 资源错配。
- 与计划脱节 → 执行无依据。
