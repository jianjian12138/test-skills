# 接口文档检查清单与常见坑（qa-api-doc）

## 1. 文档完整性检查清单
- [ ] 每个接口：方法 / 路径 / 鉴权 / 内容类型
- [ ] 请求参数：名称 / 类型 / 必填 / 约束（长度 / 枚举 / 格式）
- [ ] 响应：状态码 / 业务码 / 字段类型 / 示例
- [ ] 错误码表与含义
- [ ] 分页 / 排序 / 过滤约定

## 2. 协议覆盖
- REST / OpenAPI：主流，脚本可抓取 Swagger JSON
- GraphQL：关注 schema / query / mutation / 参数类型
- WebSocket：关注消息帧 / 事件名 / 鉴权握手

## 3. 字段约束识别
- 必填 vs 可选、默认值、可空
- 长度 / 取值范围 / 正则格式（手机号 / 邮箱 / 订单号）
- 枚举值与非法值处理

## 4. 常见坑
- 只记成功响应 → 错误码漏测。
- 参数约束不写 → 用例无法判边界。
- 鉴权方式模糊 → 执行时 401 频发。
- 多协议混用不区分 → 自动化脚本选错客户端。
