# 上线验证检查清单与常见坑（qa-release-check）

## 1. 上线前门禁
- [ ] 用例执行完成，通过率达标
- [ ] 致命/严重缺陷全部关闭
- [ ] 性能 SLA 达标（见 qa-perf-analysis）
- [ ] 安全扫描无高危未修复
- [ ] 兼容性必测组合通过（见 qa-compat-matrix）

## 2. 灰度 / 金丝雀检查
- [ ] 灰度比例阶梯（1% → 5% → 20% → 100%）
- [ ] 灰度指标对比（错误率 / RT / 业务量）
- [ ] 金丝雀分析与基线偏差阈值
- [ ] 自动回滚触发条件

## 3. 回滚预案
- [ ] 回滚步骤文档化且演练过
- [ ] 数据兼容（新老版本双向）
- [ ] 配置 / 开关可秒级回退
- [ ] 责任人 + 决策链路明确

## 4. 监控告警核对
- [ ] 核心接口错误率告警
- [ ] 资源（CPU/内存/连接）告警
- [ ] 关键业务指标（下单/支付）看板
- [ ] 日志聚合 + traceId 串联

## 5. 常见坑
- 全量直接上 → 无灰度，炸了难收。
- 回滚没演练 → 真出事手忙脚乱。
- 上线不看监控 → 问题滞后发现。
- 只验功能不验性能 → 峰值宕机。
