# 测试数据检查清单与常见坑（qa-test-data）

## 1. 数据设计方法
- 等价类划分：有效 / 无效类各取代表
- 边界值：min / min+1 / max-1 / max / 临界
- 组合：多字段异常用两两组合降冗余

## 3. 常见坑
- 用真实生产数据测试 → 合规风险，必须脱敏。
- 边界只取正常值 → 极值漏测。
- 数据写死 → 多环境不通用，用变量/CSV 驱动。
- 大数据量未造数 → 性能/分页场景无法覆盖。
