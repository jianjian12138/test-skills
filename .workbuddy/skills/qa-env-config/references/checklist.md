# 环境配置检查清单与常见坑（qa-env-config）

## 1. 多环境差异矩阵
| 项 | dev | test | staging | prod |
| --- | --- | --- | --- | --- |
| BASE_URL | ✅ | ✅ | ✅ | ✅ |
| 数据库 | 独立 | 独立 | 近生产 | 生产 |
| 第三方 | mock | mock | 真实(受限) | 真实 |
| 数据量级 | 小 | 中 | 大 | 全量 |

## 2. 密钥管理建议
- 密钥不入仓库，走 `.env` + 密钥管理（Vault / KMS）
- `.env` 不提交，仅提交 `.env.example`
- 不同环境密钥隔离，避免串环境

## 3. 常见坑
- 直接改代码里的 URL → 切环境要改代码。
- 密钥提交仓库 → 泄露风险，需 pre-commit 拦截。
- 环境差异未文档化 → 测试结论不可信。
- staging 数据量远小于生产 → 性能结论失真。
