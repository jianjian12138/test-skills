# 兼容性云测试接入指南（qa-compat-matrix）

## 1. 云真机 / 云浏览器平台

| 平台 | 适用 | 接入方式 |
| --- | --- | --- |
| BrowserStack | Web 跨浏览器/真机 | 账号 + 用户名:密钥；Selenium/Playwright remote URL |
| SauceLabs | Web 跨浏览器 | 同 BrowserStack 体系 |
| 阿里云真机 | 移动真机（国内合规） | 控制台选机 + OpenAPI |
| 腾讯 WeTest | 移动/小程序/兼容性 | 控制台 + 自动化框架接入 |

接入要点：
- 用平台提供的 **remote WebDriver URL**，把 `qa-ui-automation` 生成的 Playwright 脚本指向远端。
- 设备/浏览器矩阵来自本技能生成的 `matrix.csv`，按"需云端"列筛选。

## 2. 移动端碎片化策略

- **iOS**：版本碎片化低，优先最新 2~3 个大版本 + 主力机型（iPhone 14/15）。
- **Android**：碎片化高，按国内份额选 Top 机型（华为/小米/OV/荣耀）+ 2~3 个系统版本。
- **分辨率**：覆盖 1 个桌面视口 + 1~2 个移动视口即可抓大部分布局问题。

## 3. 国产浏览器内核注意点

| 浏览器 | 内核 | 坑 |
| --- | --- | --- |
| 微信内置 | X5 / 系统 WebView | 视频自动播放限制、JSBridge、缓存强 |
| QQ 浏览器 | X5 | 同微信内核问题 |
| UC | U3/U4 | 滚动/动画差异、广告拦截 |
| 360 | Chromium（兼容模式为 IE） | 兼容模式退化为 IE 行为 |

> 国产浏览器无法靠本地 Chrome 模拟，必须走云浏览器或真机。

## 4. 网络维度

- 弱网（高延迟/丢包）用平台"网络节流"或 `tc`/`Network Link Conditioner`。
- 重点验：超时重试、loading、断点续传、脏数据。

## 5. 常见坑

- 真机 vs 模拟器字体/渲染差异 → 关键布局用真机复验。
- iOS Safari 禁止非用户手势触发音频/视频 → 交互设计规避。
- 移动端 `100vh` 在地址栏收起时跳动 → 用 `dvh`/`100%`。
