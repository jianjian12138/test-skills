# CI/CD 配置检查清单与常见坑（qa-ci）

## 1. 质量门禁
- [ ] 通过率阈值（如 <95% 阻断合并）
- [ ] 覆盖率阈值（行/分支）
- [ ] 安全扫描无高危
- [ ] 静态检查（lint）零错误

## 2. 效率
- [ ] 并行 / 分片（pytest-xdist / 矩阵）
- [ ] 依赖与产物缓存（npm cache / pip cache）
- [ ] 失败快速失败（fail-fast）可选

## 3. 产物
- [ ] Allure / 报告归档
- [ ] 测试结果上传 artifact

## 4. 常见坑
- 无门禁 → 红也能合，质量失控。
- 全量串行 → 反馈慢，开发者绕过。
- 不缓存 → 每次装依赖，CI 超时。
- 安全扫描不接门禁 → 漏洞累积。
