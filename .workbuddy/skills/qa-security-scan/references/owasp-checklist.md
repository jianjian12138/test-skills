# OWASP Top 10 (2021) 人工核查清单

工具（ZAP/Semgrep/Trivy）覆盖不到的，靠这份清单人工 + 半自动核查。
每个条目给「测什么 / 怎么测 / 风险」。

| # | 风险 | 测什么 | 怎么测 |
| --- | --- | --- | --- |
| A01 | 失效访问控制 | 越权（水平/垂直）、未授权接口 | 用普通用户 token 访问他人资源 ID；删改请求里的 role/isAdmin |
| A02 | 加密失败 | 敏感数据明文、弱加密、HTTP | 抓包看是否 HTTPS；密码/身份证是否明文存储或日志打印 |
| A03 | 注入 | SQL / NoSQL / 命令 / XPath 注入 | 参数里塞 `' OR 1=1 --`、`` `; cat /etc/passwd``，看是否报错/执行 |
| A04 | 不安全设计 | 业务逻辑漏洞、缺乏风控 | 重复提交订单、绕过验证码、负数金额、并发抢超 |
| A05 | 安全配置错误 | 默认口令、目录遍历、暴露管理端 | 扫 `/admin`、默认账号、错误信息泄露堆栈 |
| A06 | 脆弱过时组件 | 三方库 CVE | Trivy / pip-audit（见 tool-guide） |
| A07 | 身份鉴别失败 | 弱口令、无锁屏、JWT 不校验 | 爆破登录、改 JWT alg=none、token 不过期 |
| A08 | 软件数据完整性 | 不校验签名/反序列化 | 反序列化不可信数据、依赖未锁版本被投毒 |
| A09 | 日志监控不足 | 无审计、无告警 | 越权操作是否留痕；异常是否有告警 |
| A10 | SSRF | 服务端请求伪造 | 让服务端请求内网/ metadata（169.254.169.254） |

## 业务侧高频（工具盲区）

- **越权**：水平（A 看 B 的数据）、垂直（普通用户调管理员接口）。
- **逻辑漏洞**：并发下单、库存超卖、金额篡改、优惠券复用。
- **验证码/防重放**：能否绕过、能否重放。
- **敏感信息脱敏**：返回里是否带多余字段（手机号完整、身份证完整）。
