# 安全扫描检查清单与常见坑（qa-security-scan）

## 1. OWASP Top10 覆盖清单
- [ ] A01 失效访问控制（越权 / IDOR）
- [ ] A02 加密失败（明文 / 弱算法）
- [ ] A03 注入（SQL / NoSQL / 命令）
- [ ] A04 不安全设计（业务逻辑缺陷）
- [ ] A05 安全配置错误（默认口令 / 目录遍历）
- [ ] A06 脆弱过时组件（见 SCA）
- [ ] A07 身份鉴别失败（暴力 / 会话固定）
- [ ] A08 软件数据完整性失败（供应链）
- [ ] A09 安全日志监控不足
- [ ] A10 SSRF

## 2. 工具分工
- DAST：ZAP（被动+主动爬站，出报告）
- SAST：Semgrep（代码规则扫描）
- 依赖/SCA：Trivy / pip-audit（漏洞+许可证）
- 密钥：本技能 scan_secrets.py（离线正则扫）

## 3. 常见坑
- 只跑 SAST 不跑 DAST → 漏运行时漏洞。
- 不扫依赖 → Log4j 级风险漏掉。
- 密钥硬编码进仓库 → 必须 pre-commit 拦截。
- 报告只给数量不修 → 扫描无价值。
