# 测试报告检查清单与常见坑（qa-report）

## 1. 报告必备要素
- [ ] 测试范围 / 环境 / 周期
- [ ] 用例总数 / 执行数 / 通过 / 失败 / 阻塞
- [ ] 通过率（按模块、按类型）
- [ ] 缺陷分布（模块 / 严重级 / 状态）
- [ ] 未通过项与风险说明
- [ ] 结论与发布建议（go / no-go）
- [ ] 多轮趋势（见 scripts/trend_compare.py）

## 2. 质量评估口径
- 通过率 = 通过 / (执行 - 阻塞)
- 严重级加权：致命/严重未清 → 一票 no-go
- 缺陷收敛：本轮新增 vs 关闭趋势

## 3. 常见坑
- 只给通过率不含缺陷分布 → 看不出风险点。
- 不写发布建议 → 报告无决策价值。
- 多轮不比对 → 无法判断质量走势。
- 把阻塞当失败 → 指标失真。
